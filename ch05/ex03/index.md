# 問題

1. "Jan","Feb","Mar","Apr","May","Jun","Jul","Aug","Sep","Oct","Nov","Dec"のいずれかの文字列リテラルを受け取って、その月の日数が31であれば true、そうでなければ false を返すメソッドを書きなさい。if-else を使うバージョンと switch を使うバージョンの両方を作りなさい。
2. if-else を使う場合と switch を使う場合で、それぞれ可読性に対してどのようなメリットがあるか書きなさい。

# 回答

if-else を使う場合、具体的な条件式を記載するため、具体的にどういう比較をしているか、今回であれば、month を同値演算子(===)で比較しているということが分かりやすい。

switch を使う場合、case の直後に比較する式が書いてあるため、今回であれば日数が31日の月がわかりやすい。また、switch (month) と比較対象を最初に書くので、month の値によって処理が分岐することがわかりやすい。 なお、switch は switch 直後の式の値と、各 case の式の値を同値演算子(===)で比較するが、この仕様を知らなければ == か === で比較するのか分からないデメリットもある。
