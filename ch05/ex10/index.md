# 問題

`with` 文は最適化が難しくなるだけでなく混乱を招く可能性がある。
このことを理解するために以下の 4 ブロックを実行し、`console.log` の出力および `with` 文を使わずに同じ処理を書く場合にどのような文になるかを書きなさい。

# 回答

まず、with 文は与えられたオブジェクトのプロパティを、そのブロック内で変数として扱えるようにするものである。

## 1つ目のコードブロック

with 文内の a, b はそれぞれ、obj.a, obj.b である。
よって同じ処理を行うためには、コメントアウトした部分に置き換えればよい。

```
{
  let a = 1;
  let b = 2;
  let obj = { a: 3, b: 4 };
  with (obj) {
    a = b;
  }
  // with 文を使わずに同じ処理を書く場合：
  // obj.a = obj.b
  console.log({ a, b, obj });
  // 出力：{ a: 1, b: 2, obj: { a: 4, b: 4 } }
}
```

## 2つ目のコードブロック

obj には、プロパティに b のみを持つため、with 文内の b は、obj.b である。
よって同じ処理を行うためには、コメントアウトした部分に置き換えればよい。

```
{
  let a = 1;
  let b = 2;
  let obj = { b: 4 };
  with (obj) {
    a = b;
  }
  // with 文を使わずに同じ処理を書く場合：
  // a = obj.b
  console.log({ a, b, obj });
  // 出力：{ a: 4, b: 2, obj: { b: 4 } }
}
```

## 3つ目のコードブロック

obj には、プロパティに a のみを持つため、with 文内の a は、obj.a である。
よって同じ処理を行うためには、コメントアウトした部分に置き換えればよい。

```
{
  let a = 1;
  let b = 2;
  let obj = { a: 3 };
  with (obj) {
    a = b; // obj.a = b と同じ意味
  }
  // with 文を使わずに同じ処理を書く場合：
  // obj.a = b
  console.log({ a, b, obj });
  // 出力：{ a: 1, b: 2, obj: {a: 2}}
}
```

## 4つ目のコードブロック

obj の中に a, b プロパティはないため、with 文内の a, b は、with 文の前で宣言された a, b である。
よって同じ処理を行うためには、コメントアウトした部分に置き換えればよい。

```
{
  let a = 1;
  let b = 2;
  let obj = {};
  with (obj) {
    a = b;
  }
  // with 文を使わずに同じ処理を書く場合：
  // a = b
  console.log({ a, b, obj });
  // 出力：{ a: 2, b: 2, obj: {}}
}
```
