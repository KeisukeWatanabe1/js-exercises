# 質問 1

console.log の出力をどうテストするか質問した

以下の回答を得た

- console.log は戻り値を返さないため、expect で確かめることはできない。呼び出しそのものを記録するやり方になる
- vi.spyOn(obj, "method") を使うと、obj.method が「呼び出しを記録する関数」に置き換わる
- .mockImplementation(() => {}) を付けると、テスト中の実際の出力が出なくなる
- 上記の差し替えを行ったままだと他のテストに影響するので、テストが終わったらもとに戻す (mockRestore) をする必要がある

# 質問 2

テストで現在時刻を確認する方法を質問した

以下の回答を得た

- 現在時刻のように呼ぶたびに値が変わるものは、toBe で比較できない。
- そのため、テストでは、「範囲で確認する」か「時刻を固定する」のが一般的
- 「時刻を固定する」場合は、vi.useFakeTimers() と vi.setSystemTime(...) で現在時刻を固定すると、値を厳密に比較できる
