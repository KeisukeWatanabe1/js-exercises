# 問題

以下のコードが Web サービスの一部で使われており、引数の input には Web サービスの利用者が入力した文字列が渡されるものとする。

```
function f(input) {
  const f = new Function(`return "Hello, " + ${input}`);
  console.log(f());
}
```

このコードには重大な問題が含まれている。何が問題と考えられるか記述しなさい。 また問題を実証できるコードも記載しなさい。

# 回答

問題は主に2つある。

1つ目は、例えば、f("Watanabe") と呼び出すと、関数 f 内でテンプレートリテラルが展開されたとき、以下のようになり、`Watanabe` は変数名となる。しかし、`Watanabe` という変数は定義されていないため、ReferenceError となってしまう。

```
return "Hello, " + Watanabe
```

2つ目は、f の引数に、何らかの処理を文字列として渡すと、関数内でその処理が実行できてしまうことである。
例えば、以下のように無限ループを走らせる、関数を実行する文字列を記載すると、無限ループが起きてしまう。

```
f("function() {while (true) {1 + 1} } ()");
```
