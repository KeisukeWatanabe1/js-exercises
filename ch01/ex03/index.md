# 問題
Web ブラウザに以下の URL のブックマークを追加しなさい。追加したブックマークを開くと何が起こるか確認し結果を記載しなさい。

```
javascript:alert("Hello, World!")
```

# 回答
追加したブックマークを開くと、"Hello, World"とダイアログが表示された。

この理由を示す。URLの先頭がjavascript:となっているので、ブラウザがこれ以降をjavascriptとして実行する。なお、URLにhttpやhttpsを含まないため画面遷移は起きず、現在開いているページで実行される。alert()はダイアログを表示するメソッドであるため、"Hello, World!"が表示される。
