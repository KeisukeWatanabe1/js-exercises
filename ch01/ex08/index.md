# 実行方法

以下をpowershellで実行した

```sh
# コンソールに出力する文字をUTF-8にエンコーディングする設定
$OutputEncoding = [System.Text.Encoding]::UTF8

# プログラムを実行
cat .\sorekara.txt | node .\index.ts
```
