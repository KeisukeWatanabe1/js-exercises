# 問題

$ や \_ を変数名として利用するライブラリを調べなさい。

# 回答

## \$を変数名として利用するライブラリ

$を利用するライブラリの一つとしてjQueryがある。

jQueryはWebブラウザ上でJavaScriptでできる処理を簡単に記述するためのライブラリである。
書き方は以下である。aはセレクタ、bはメソッドを表す。

```
$("a").b();
```

例えば、ボタンが押されたとき何か処理を行いたい時は以下のように書く。

```
$("button").click(function() {
    // ボタンを押した時の処理
});
```

\$はjQueryライブラリにおいて、jQueryのエイリアスとなっている。jQueryと毎回打つのは大変なので、 \$の一文字で済むようになっている。

## \$を変数名として利用するライブラリ

\_を変数名として使うライブラリにUnderscore.js, Lodashがある。どちらも配列操作、オブジェクト操作、数値操作などの機能をまとめて提供しているユーティリティライブラリである。例えば、配列の各要素に対して処理を行う操作は、以下のように書く。

```
_.each([1, 2, 3], function(value, index){
    console.log(value);
});
```

## \$や\_を変数名として使える理由

JavaScriptでは変数を指定する識別子のルール、先頭の文字はUnicode文字、\$、\_のいずれかにすると決まっているためである。
