# 問題

"𠮷野家"[0]や "👨‍👨‍👧‍👧"[0] が何を返すか調べなさい。それぞれの結果について説明しなさい。問題 7.8 で得た絵文字に対する知見も述べなさい。

# 回答

node 環境で確かめた結果を以下に示す。

```
> "𠮷野家"[0]
'\ud842'
> "👨‍👨‍👧‍👧"[0]
'\ud83d'
```

JavaScript では文字列は、UTF-16形式であらわす。
UTF-16は文字を16ビットに符号化する。符号化する文字が基本多言語面（BMP。様々な言語のよく使われる文字が収録されている）であれば、1つの16ビット符号で表し、BMPでなければ2つの16ビット符号で表す。文字列の各インデックスには、この16ビット符号が格納されている。

"𠮷"はBMPではないため、2つの16ビット符号で、"D842 DFB7"と表される。よって、`"𠮷野家"[0]` では"𠮷"の1つ目の16ビット符号である、`\ud842`が表示される。

絵文字"👨‍👨‍👧‍👧"は、4つの絵文字"👨👨👧👧"でゼロ幅接合子によって1つの絵文字として表されている。よって、`"👨‍👨‍👧‍👧"[0]`では、"👨"の16ビット符号`\ud83d \udc68`のうち最初の`\ud83d`が表示される。

## 絵文字に対する知見

前述のように、絵文字"👨‍👨‍👧‍👧" は4つの絵文字"👨👨👧👧"と3つのゼロ幅接合子で構成されている。これら1つの絵文字は2つの16ビットで表されるため、"👨‍👨‍👧‍👧"の長さは、以下のように11となる。

```
> "👨‍👨‍👧‍👧".length
11
```
