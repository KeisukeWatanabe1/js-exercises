# 問題

以下のプログラムは 1 から 100 までの FizzBuzz を出力する。
Fizz、Buzz、FizzBuzz、数値、それぞれのケースで式がどのように評価されるか言及しつつ処理を説明しなさい。

```javascript
for (i = 1; i < 101; i++)
  console.log((i % 3 ? "" : "Fizz") + (i % 5 ? "" : "Buzz") || i);
```

# 回答

## 論理和演算子（||）

論理和演算子(||)は、まず演算子の左辺の式を評価し、trueに変換される場合は、左辺の式の値を返し、falseに変換される場合は、右辺の式の値を返す演算子である。

||の左辺と右辺がiの値によってどう評価されるかという視点でプログラムを説明する。

## iが3の倍数であり、かつ5の倍数ではない場合

`i`が3で割り切れるため、||の左辺は"Fizz"+""で、"Fizz"となる。"Fizz"はtrueに変換されるため、||の左辺"Fizz"がそのまま返される。

## iが3の倍数ではなく、かつ5の倍数である場合

`i`が5で割り切れるため、||の左辺は""+"Buzz"で、"Buzz"となる。"Buzz"はtrueに変換されるため、||の左辺"Buzz"が返される。

## iが3の倍数かつ5の倍数である場合

`i`が3と5で割り切れるため、||の左辺は"Fizz"+"Buzz"で、"FizzBuzz"となる。"FizzBuzz"はtrueに変換されるため、||の左辺"FizzBuzz"が返される。

## iが上記以外（3の倍数ではなく、かつ5の倍数ではない場合）

`i`が3でも5でも割り切れないため、||の左辺は""となる。""(空文字列)はfalseに変換されるため、||右辺オペランド`i`が返される。
